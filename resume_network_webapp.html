سوابق شغلی و تجارب اجرایی

مهندس ارشد نرم‌افزار، توسعه وب و زیرساخت شبکه و امنیت ۱۳۹۹ - اکنون (بیش از ۵ سال)
شرکت بهار تجارت (Bahar Tejarat Co.)
  • توسعه فول‌استک وب‌اپلیکیشن‌ها و سرویس‌های نرم‌افزاری: طراحی، برنامه‌نویسی و استقرار پلتفرم‌های تحت وب پیشرفته و وب‌سایت‌های تجاری شرکت بر پایه Next.js (SSR/SSG)، React.js، TypeScript و Tailwind CSS با بک‌اند مدرن Payload CMS و پایگاه‌های داده MongoDB و PostgreSQL، به همراه ساخت اپلیکیشن‌های موبایل با Flutter و فایربیس.
  • معماری Multi-Cloud و استقرار کانتینری (DevOps): میزبانی و راه‌اندازی سرورهای VPS لینوکسی روی ارائه‌دهندگان معتبر بین‌المللی (AWS, GCP, Azure, Oracle Cloud, Hetzner, Vultr)، کانتینری‌سازی سرویس‌ها با Docker و ایجاد خطوط لوله استقرار خودکار با GitHub Actions.
  • امنیت ابری با Cloudflare Zero Trust و Cloudflare Tunnel: استقرار پلتفرم Cloudflare Zero Trust و پیکربندی تونل‌های امن Cloudflare Tunnel (cloudflared) جهت ایجاد دسترسی ریموت رمزنگاری‌شده به سرویس‌های داخلی شرکت بدون نیاز به باز کردن پورت‌های آسیب‌پذیر و محافظت لایه لبه با CDN و فایروال WAF.
  • معماری Multi-WAN و لود بالانسینگ شبکه: طراحی، پیاده‌سازی و مدیریت شبکه سازمانی با ۳۰ تا بیش از ۵۰ دستگاه و کلاینت فعال؛ راه‌اندازی لود بالانسینگ هوشمند روی ۳ آپ‌لینک مستقل WAN با Failover آنی جهت تضمین پایداری ۹۹.۹٪ اتصال اینترنت.
  • امنیت سازمانی و مانیتورینگ متمرکز با Wazuh SIEM/XDR: استقرار سرورهای Windows Server و پلتفرم امنیت سازمانی Wazuh جهت پایش متمرکز لاگ‌ها، مانیتورینگ بلادرنگ رویدادهای امنیتی، ارزیابی آسیب‌پذیری‌ها و تشخیص نفوذ در سراسر اندپوینت‌ها.
  • اتصال شعب با Site-to-Site VPN و فیلترینگ AdGuard Home: طراحی و راه‌اندازی تونل‌های رمزنگاری‌شده Site-to-Site VPN برای اتصال امن و بی‌وقفه شعب شرکت به مرکز داده؛ استقرار AdGuard Home جهت فیلترینگ هوشمند DNS و مهار بدافزارها.
  • مدیریت Active Directory با استانداردهای امنیتی: پیکربندی و نگهداری متمرکز Active Directory Domain Services (AD DS)، اعمال پالیسی‌های سخت‌گیرانه امنیتی (GPO) با تفکیک سطوح دسترسی (Least Privilege) و استقرار خودکار سیستم‌های عامل ویندوز و لینوکس تحت شبکه.
  • شبکه بی‌سیم متمرکز با رومینگ هوشمند و نظارت تصویری: راه‌اندازی معماری Multi-AP با رومینگ بی‌وقفه (802.11k/v/r) و هدایت باند فرکانسی (Band Steering بین 2.4GHz و 5GHz)؛ مدیریت یکپارچه دوربین‌های امنیتی IP و دستگاه‌های NVR/DVR با تفکیک ساب‌نت‌ها.
